  applied ectt's own no-anchors project-file rule to Ceedling's format). Fixed; aliases resolve, bombs and cycles are
  refused.
- **ReqIF:** the export wrote `REQ-IF-VERSION` `1.2`; the OMG schema fixes it to `1.0`. Found by validating against
  the real `reqif.xsd` (zero errors now). The XSD is not vendored, so the conformance test skips unless
  `ECTT_REQIF_XSD` points at a copy and `xmlschema` is installed.

Other defects in existing code, each fixed with a regression test: the ReqIF importer did not read the schema's own
reference form; the cmocka parser missed real `[       OK ]` lines; the report reader could not load merged CI
reports.
