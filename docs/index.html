Architecture diagrams

Embedded C unit test tool — 24 components, 7 layers, 69 dependency edges.

These diagrams render the component graph held in design/trace/design-elements.yaml, which is the authoritative register. Where a diagram and the register disagree, the diagram is wrong — and trace_check.py --check-diagrams fails the build when they do. Each page is a standalone interactive artifact: pan, zoom, search, trace a relationship, switch theme, export.

How to read the set

In a per-layer view, solid nodes are the components that view owns — every one of their dependencies is drawn. Nodes tagged · context are dependency targets that live in another layer; their own edges belong to the view that owns them. Between them the eight component views own all 24 components exactly once. There is deliberately no single whole-system component diagram: 24 nodes and 69 edges on one page is a picture nobody reads, so the layer map carries the shape and the per-layer views carry the detail.
