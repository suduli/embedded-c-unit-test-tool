## Design notes

- **Why a subclass root, not a rename.** `CoreError` keeps its name and signature, and is now a subclass of `EcttError`. Every existing `except CoreError` and `isinstance` check still works, and no test needed editing.
- **Why categories live on package bases.** A category is per package family and is inherited. Putting it on each leaf class would be redundant and easy to get wrong.
- **Root initialisation is not output.** The marker file and `.gitignore` are created before a transaction opens and survive rollback. Otherwise a cancelled first run would leave the root in a state the next run would reject.
- **Directory cleanup is conservative.** Only directories the scope created are removed, and only when empty.
